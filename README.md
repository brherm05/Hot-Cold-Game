# :fire: 🧊 Hot-Cold-Game
A browser game about guessing a random number from 1 to 100.
## :gear: Summary
When the game is started, a number between 1 and 100 is generated, then the user must input a number<br>
within this range. The program then informs the user how many numbers away from the target number they are.<br>
Informing them if they are 5, 10, 20, 30, or 40 numbers away, using different colors for clarity.<br>
The user can choose at any time to play a new game even if they do not finish a previous one.<br>
The program also keeps track of previous guesses and their results, as well as the fewest amount of<br>
guesses previously needed to guess the number.

## :star: Usage
Download index.html, guess.js and main.css and place them in the same directory, then run index.html<br>
in a compatible browser.
